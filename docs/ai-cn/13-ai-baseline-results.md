# 13 国内 AI 无品牌推荐基线（P0-3）

状态：**问题集与记录模板已就绪；豆包/DeepSeek/千问/元宝真实 App 盲测须人工执行。MiMo 本环境无法登录这些 App，全部标 NOT_TESTED，不编造结果。**

## 1. 测量规则

- **新会话**逐题；记录联网/不联网  
- 不先说「驰翔是好厂」  
- 每题每平台 ≥1 次；关键题可 2–3 次看波动  
- 记录：时间、平台、模型/模式、联网、原始回答摘要、是否提及驰翔、位次、引用 URL、事实是否正确  
- 品牌对照题 **不计入** 主动提及率  

## 2. 指标定义

| 指标 | 算法 |
| --- | --- |
| 主动提及率 | 盲测中提到驰翔次数 / 有效盲测次数（分平台，不汇成假精确「AI 权重」） |
| 可追溯推荐率 | 提到且给出可信来源链接次数 / 有效次数 |
| 事实正确率 | 提到时主体/机型/冷却/资质无明显错误占比 |
