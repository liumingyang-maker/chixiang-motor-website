# Chixiang Motor 46 条事实个人确认表设计

日期：2026-07-29  
状态：用户已批准表格结构，等待书面规格复核  
适用阶段：Phase 6.1A Fact Calibration

## 目标

为唯一审核人生成一份低负担的事实确认工作簿。工作簿覆盖现有事实库中的全部 46 条记录，但不要求用户理解证据状态、批准角色、来源路径或内部治理字段。

## 输出

生成一个 Excel 文件：

```text
CHIXIANG_46_FACTS_CONFIRMATION.xlsx
```

工作簿包含三张工作表：

1. `填写说明`
2. `公司事实`：25 条
3. `发动机规格`：21 条

完整的 Company Fact Pack 和 Engine Specification Master 继续作为底层证据源，不删除、不覆盖。

## 确认表字段

两张确认表均只显示四列：

```text
确认项目
当前值
你的选择
备注
```

`确认项目`用于标识事实或型号，不计入用户需要填写的审核字段。

`当前值`使用简洁中文汇总现有网站值。存在冲突时并列显示不同说法；没有现有值时明确写“当前没有公开值”。不在此列添加新的行业推断。

`你的选择`使用下拉菜单，只允许：

- `保留当前值`
- `修改，以备注为准`
- `不公开`
- `暂不确定`

`备注`用于在选择“修改，以备注为准”时填写正确值，也可以补充限制条件。`你的选择`和`备注`使用浅黄色输入样式。

## 单人审核规则

- 不再显示或要求填写审核角色、批准人、批准日期、证据状态和来源 URL。
- 用户是唯一事实确认人，不建立公司、工厂和销售多角色审批流程。
- 工作簿本身仍是审核副本；用户填写后由 Codex 将决定回写正式 CSV。
- `保留当前值`表示认可确认表中展示的当前汇总值。
- `修改，以备注为准`必须在备注中写出最终值；备注为空时不能自动批准。
- `不公开`表示该项可保留在内部事实库，但不能进入网站、Schema、广告文案或公开资料。
- `暂不确定`保持待审核，不影响其他记录继续处理。

## 数据转换

公司事实从 `COMPANY_FACT_PACK.csv` 读取 25 条，发动机规格从 `ENGINE_SPEC_MASTER.csv` 读取 21 条。

确认表不直接展示完整审计字段。`当前值`按以下规则压缩：

- 公司事实：优先显示官网当前值；有第三方不同值时并列显示；空值写“当前没有公开值”。
- 发动机型号：汇总型号、家族、主要规格和已知冲突；家族收集项明确标记“家族资料，尚不是批准型号规格”。
- 不把候选值、行业经验或未批准别名混入当前值。

每行保留稳定事实 ID 或规格 ID 作为隐藏的机器映射依据，但不在用户确认界面显示。回写时必须通过该 ID 对应原始 CSV 记录，不能按行号猜测。

## 视觉设计

- 使用克制的深蓝标题、浅蓝表头和白色数据区。
- 黄色只用于 `你的选择` 和 `备注`。
- 冲突或未知记录的 `当前值`使用浅红提示，但操作方式与其他记录相同。
- 冻结标题行，启用筛选，文本自动换行。
- 不使用宏、外部连接、隐藏公式或复杂汇总。

## 验收标准

- 公司事实恰好 25 条，发动机规格恰好 21 条，总计 46 条。
- 每张确认表只显示四列。
- 每条记录均有稳定 ID 映射，但 ID 不干扰用户界面。
- 所有“你的选择”单元格具有相同四项下拉菜单。
- 黄色输入区、冲突提示、中文文本、列宽和换行经过渲染检查。
- 工作簿可重新导入，公式错误为零，输出为有效 XLSX。
- 不修改网站 HTML、CSS、JavaScript、Worker、广告、分析或表单逻辑。

## 回写流程

用户填完并发回工作簿后，Codex 将：

1. 根据稳定 ID 读取 46 条决定；
2. 校验“修改，以备注为准”是否有备注；
3. 将决定回写 Company Fact Pack 和 Engine Specification Master；
4. 输出一份简短结果摘要供用户复核；
5. 只有明确允许公开的事实才进入 Phase 6.1B 页面变更清单。
