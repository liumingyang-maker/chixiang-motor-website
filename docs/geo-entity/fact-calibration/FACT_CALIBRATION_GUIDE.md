# Chixiang Motor 事实校准审核指南

## 使用范围

本目录用于校准公司事实和发动机规格。CSV 是唯一可版本控制的事实源；Excel 是便于公司、工厂和销售人员审核的副本。Excel 中的决定只有回写 CSV 并通过校验后，才能进入后续页面修改计划。

## 事实源与优先级

事实必须保留可复查的 URL、仓库路径或受控证据编号。第三方平台和市场资料只能证明其自身记录的内容，不能自动覆盖公司或工厂批准值。

审核时按以下顺序判断证据：

1. 已批准的公司或工厂受控文件，并记录安全的证据编号；
2. 已批准的工厂规格记录；
3. 当前正式网站与内容一致的仓库源文件；
4. Phase 6.0 审计记录和冻结的研究材料；
5. 可公开引用、能够回访的第三方来源；
6. 无支持证据的推断。

高优先级来源不是自动正确答案。同一字段存在冲突时必须并列保留来源和值，直到责任人批准。第 6 类只能标记为 `UNKNOWN`，不能进入候选值或批准值。

## 证据状态

- `VERIFIED`：当前范围内有直接、可复查且无冲突的证据。
- `SUPPORTED`：存在支持证据，但独立验证或完整资料不足。
- `CONFLICTING`：不同来源给出不一致值。
- `UNKNOWN`：现有证据不能回答。

## 批准状态

- `PENDING_REVIEW`：等待指定责任人审核。
- `APPROVED_PUBLIC`：允许用于网站和其他公开材料。
- `APPROVED_INTERNAL_ONLY`：只能用于内部决策。
- `REJECTED`：明确不采用。
- `RETIRED`：曾经采用但已经失效。

## 公司事实审核责任

公司身份、地址、产能、认证、品牌和公司介绍由公司管理负责人审核。网站中已经出现不代表已经完成本事实包的公开批准。

## 发动机规格审核责任

型号、排量、缸径行程、启动、离合器、挡位、倒挡、冷却和适配限制由工厂技术负责人审核。不能从型号代码、行业习惯、图片或市场页面示例反推规格。

## 商业政策审核责任

MOQ、样品政策、混批、OEM/ODM、物流建议、配件支持和销售联系方式由销售管理负责人审核。市场页面中的现有措辞只能作为当前网站值，不能替代商业政策批准。

## 审核流程

1. Codex 从现有网页、仓库源文件、审计材料和可引用的公开来源预填当前值与冲突；
2. 公司管理负责人审核公司身份、地址、品牌、产能、认证与公开介绍；
3. 工厂技术负责人审核发动机型号、规格、配置和适配边界；
4. 销售管理负责人审核商业政策、市场适用范围与联系方式；
5. 责任人填写候选或批准值、允许公开的中英文措辞、审核人和审核日期；
6. Codex 将决定回写 CSV，运行一致性校验，再生成逐页变更清单。

## 本轮单人审核约定

2026-07-29 的简化确认由网站所有者作为唯一审核人完成，不再要求公司、工厂和销售角色分别签字。CSV 中的 `review_owner_role` 继续保留为事实归属提示，`approved_by` 统一记录为 `Site Owner`。

单人确认不取消公开安全条件。ISO、CCC 等缺少证书编号、主体、范围或有效期的认证声明仍保持 `PENDING_REVIEW`；`FAMILY_INTAKE` 即使完成家族关系确认，也只能标记为 `APPROVED_INTERNAL_ONLY`；用户选择“暂不确定”的记录继续保留冲突和空白值。

当前 CSV 中空白的 `approved_by` 和 `approved_date` 是有意保留的待审核字段，不是遗漏。未解决记录可以继续保留，但必须保持 `CONFLICTING`、`UNKNOWN` 或 `PENDING_REVIEW`，不能静默删除。

## 公开条件

只有批准值完整、证据可追溯、审核人和审核日期齐全，且证据状态不是 `CONFLICTING` 或 `UNKNOWN` 的记录，才能标记为 `APPROVED_PUBLIC`。

- `APPROVED_PUBLIC` 可以进入网站正文、Schema、广告文案和公开销售资料；
- `APPROVED_INTERNAL_ONLY` 只能用于内部决策，不得进入公开内容；
- `FAMILY_INTAKE` 只用于收集家族层级线索，不能发布成型号级规格，也不能标记为 `APPROVED_PUBLIC`；
- 未验证的应用场景只能表述为常见用途或待确认方向，不能写成适配保证；
- 认证、产能、出口国家数、良率和工厂面积等信任声明，必须具有与措辞对应的有效证据。

## 私密证据处理

营业执照、证书原件、身份证、私人联系方式、客户聊天和原始销售记录不进入 Git。需要引用时只记录受控证据编号或用户批准的安全位置。

## 回写与版本管理

审核人员可在 Excel 副本中填写意见。正式决定必须回写对应 CSV，并保留稳定 ID、来源、批准人、批准日期和修订说明。

## Phase 6.1B 进入条件

Phase 6.1B 只能读取 `APPROVED_PUBLIC` 记录生成逐页变更清单。公司或发动机事实仍为冲突、未知或仅内部批准时，不得进入公开页面、Schema、广告文案或销售资料。

修改 `/en/about`、`/en/horizontal-engine`、`/en/`、`/en/cg-engine`、`/en/products` 或任何市场页之前，必须先输出逐页变更表，至少包含：事实 ID、批准措辞、目标页面、目标区块、当前内容、拟修改内容、证据、风险和验证方法。未进入变更表的事实不得顺带修改。

本阶段不会修改 HTML、CSS、JavaScript、Worker、Schema、Sitemap、robots、广告标签、分析标签或表单逻辑。
