# 俄罗斯卧式发动机 CX/YX 型号与规格治理设计

日期：2026-07-30
状态：书面规格，等待网站所有者最终复核

## 1. 目标

统一俄罗斯卧式发动机页面、事实表、表单与后续结构化数据中的品牌型号、俄罗斯市场参考名称和配置表达。页面既要建立 CX 品牌型号，也要覆盖俄罗斯买家熟悉的 YX 搜索叫法，但不得把 CHIXIANG 产品误写为 Yinxiang 产品。

本设计只确定事实、命名、内容结构和测试边界。用户批准书面规格以前，不修改生产 HTML，不推送，不创建 PR，不部署。

## 2. 已批准的型号体系

正式品牌型号采用 `CX + 实际型号代码`：

| 标称排量 | 正式营销型号 | 俄罗斯市场辅助名称 | 冷却 |
| --- | --- | --- | --- |
| 110 cm³ | `CX152FMH` | `YX152FMH / YX110-class` | 风冷 |
| 125 cm³ | `CX153FMI` | `YX153FMI / YX125-class` | 风冷 |
| 125 cm³ | `CX154FMI` | `YX154FMI / YX125-class` | 风冷 |
| 140 cm³ | `CX1P56FMJ` | `YX1P56FMJ / YX140-class` | 风冷 |
| 150 cm³ | `CX1P60FMJ` | `YX1P60FMJ / YX150-class / W150-2` | 风冷并带缸头内部油冷油路，无外置机油散热器 |

`CX152FMH-5B` 和 `CX152FMH-6` 不作为公开正式型号。152FMH 的启动、离合和变速箱差异作为订购配置表达，不使用宗申后缀体系代替 CHIXIANG 配置管理。

## 3. CX 与 YX 的公开关系

1. `CX` 是 CHIXIANG 正式型号前缀。
2. `YX` 作为俄罗斯市场熟悉的搜索与选型参考名称，与 CX 名称同时出现在可见页面中。
3. 页面不得把制造商或品牌写成 Yinxiang，不得使用“银翔原装”“YX 原厂”等表述。
4. 产品卡统一先显示 CX 正式型号，再显示 YX 市场参考名称。
5. 页面设置一次统一说明，不在每张卡片重复长免责声明：

```text
Обозначения YX приведены как привычные российскому рынку названия класса и ориентиры для подбора. Двигатели серии CX производит CHIXIANG MOTOR.
```

中文含义：YX 名称作为俄罗斯市场熟悉的类别名称和选型参考；CX 系列发动机由 CHIXIANG MOTOR 生产。

## 4. 已批准的配置规则

### 4.1 启动

- 五个型号均提供脚启动版本和电启动版本。
- 脚启动不区分上置或下置。
- 电启动版本可选择上置电启动或下置电启动。
- 页面和规格表必须把“启动方式”与“电启动机位置”拆成两个字段，不能继续使用 `上置 / 电启动` 这类跨维度组合。

### 4.2 离合器

| 型号 | 批准配置 |
| --- | --- |
| `CX152FMH` | 机械或半自动 |
| `CX153FMI` | 机械或半自动 |
| `CX154FMI` | 机械 |
| `CX1P56FMJ` | 机械或半自动 |
| `CX1P60FMJ` | 机械或半自动 |

`CX152FMH` 不再公开写成自动离合。

### 4.3 变速箱与倒挡

- 常规版本公开为 4 挡，不公开未确认的具体换挡顺序。
- 110、125、140、150 cm³ 均可提供内置倒挡配置。
- 110、125、140、150 cm³ 均可提供 1+1 变速箱，即一个前进挡和一个倒挡。
- 内置倒挡和 1+1 只出现在“其他可选配置”中，不进入 Hero，不作为核心卖点，也不默认绑定到某一个基础型号。

### 4.4 150 cm³ 冷却结构

- `CX1P60FMJ` 是 150 cm³ 营销型号。
- 产品定位来源于 140 级结构的升级方向。
- 冷却结构为风冷并带缸头内部油冷油路。
- 没有外置机油散热器，因此不得展示外置散热器、油管或相关图片，也不得写成带外置油冷排的版本。
- 俄语优先使用精确描述：

```text
воздушное охлаждение с масляным контуром головки цилиндра, без внешнего масляного радиатора
```

## 5. 规格数值治理

网站所有者选择公开实际排量、缸径和行程，但这些数值必须来自 CHIXIANG 工厂规格、铭牌、图纸或实测记录，不能从 Yinxiang、Zongshen 或俄罗斯零售商页面复制为 CHIXIANG 事实。

实施计划必须先建立一份规格确认表，至少包含：

```text
正式型号
俄罗斯市场参考名称
标称排量
实际排量
缸径
行程
冷却结构
启动方式
电启动机位置
离合器
常规挡位数
倒挡配置
证据来源
所有者确认状态
公开状态
```

Codex 负责提供表格、整理公开市场参考值并标记来源；网站所有者负责确认 CHIXIANG 实际值。未获确认的实际排量、缸径和行程保持 `BLOCKED_EVIDENCE`，不进入公开页面或结构化数据。标称排量可以按本设计公开。

## 7. SEO、GEO 与结构化数据

### 7.1 可见内容

- Title、Description、正文产品卡和选型内容可以同时出现 CX 正式型号与 YX 市场参考名称。
- H1 继续以俄罗斯 B2B 卧式发动机采购意图为主，不堆叠全部型号。
- YX 搜索词必须出现在可见、自然的俄语内容中，不通过隐藏文本或关键词堆砌实现。

### 7.2 结构化数据

- `brand` 与 `manufacturer` 使用 `CX MOTOR / CHIXIANG MOTOR`。
- `model` 使用 CX 正式型号。
- 不把 Yinxiang 或 YX 写入制造商品牌字段。
- YX 市场参考名称不进入官方 `model` 字段；可见正文负责承载该搜索语义。
- 实际排量、缸径和行程只有在规格确认表状态为 `APPROVED_PUBLIC` 后才能进入结构化数据。

### 7.3 表单与线索数据

- 表单选项和值使用 CX 正式型号，避免销售邮件继续只显示无品牌代码。
- 可在表单可见标签中附带短 YX 参考名称，但提交值以 CX 型号为准。
- 不修改表单端点、Turnstile、Worker、邮件发送、Google Ads 或 Yandex Metrica 成功回调。

## 8. 实施范围

首轮涉及：

1. 俄罗斯卧式发动机落地页的产品卡、对比表、移动对比、表单型号和相关 Meta 文案；
2. 英文卧式发动机 Owner 页面中的同型号事实；
3. `ENGINE_SPEC_MASTER.csv` 中卧式发动机记录；
4. 后续 Schema 设计使用的 CX 正式型号映射；
5. 事实一致性和回归测试。

本轮不新增产品 URL，不改页面视觉系统，不新增广告活动，不调整价格、MOQ、运输政策或联系渠道。

## 9. 验收标准

- 公开页面不再把 `CX152FMH` 写成自动离合；
- 启动方式与电启动机位置分成两个字段；
- 五个正式型号均使用 CX 前缀；
- 五个产品卡均显示已批准的 YX 市场参考名称；
- 150 cm³明确为缸头内部油冷油路且无外置散热器；
- 倒挡和 1+1 只作为补充配置出现；
- 未批准的实际排量、缸径和行程不公开；
- Schema 不把 YX 或 Yinxiang 写成 CHIXIANG 产品品牌；
- 表单成功条件和所有广告转化逻辑保持不变；
- 桌面、390×844、768×1024 和 1024×1366 视口均无新增溢出或裁切；
- 自动化测试全部通过，并在用户审核本地预览以后才允许推送。
