AC320 ATV / UTV Engine

Factory model AC320 (alias 175MN) is a liquid-cooled ATV/UTV engine with CVT (L-H-N-R) and built-in reverse for off-road and beach-vehicle projects.

ATV / UTV 287cc Liquid-cooled CVT + Reverse

Technical specifications

Parameter Value
Model AC320
Alias 175MN
Configuration Single-cylinder, 4-stroke, liquid-cooled, vertical
Nominal displacement 287 cc
Actual displacement 287.2 cc
Bore × stroke 75 × 65 mm
Cooling Liquid-cooled
Clutch Reinforced 5-jaw centrifugal clutch
Transmission CVT; L-H-N-R
Reverse Built-in reverse
Ignition CDI

Applications

Engineered for ATV, UTV, and off-road beach vehicle chassis with 287.2 cc liquid-cooled CVT output and integrated reverse.

Before quotation

Confirm mounting, output shaft, driveline, cooling package and vehicle integration before quotation. OEM options are not established at model level.
