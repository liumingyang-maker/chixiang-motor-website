# 乌兹别克斯坦 CG 发动机落地页设计

## 背景

驰翔摩托正在投放面向乌兹别克斯坦的俄语 Google 搜索广告。当前广告落到通用 CG 页面，只覆盖 CG 150–250cc，无法在同一页面清楚区分普通 CG、CG 水冷与 CG 重载水冷的适用工况。

本设计新增一个乌兹别克斯坦专用俄语落地页，在保持产品技术口径准确的前提下，帮助进口商、经销商和整车厂快速选型并通过 WhatsApp 或询价表单联系。

## 目标

- 用一个页面覆盖 CG 风冷、CG 水冷和 CG 重载水冷三类采购需求。
- 让来自搜索广告的采购商在几十秒内理解三类产品的区别。
- 以 WhatsApp 为主要转化路径，以完整询价表单为次要转化路径。
- 为当前 CG 广告组和未来重载广告组提供可直接跳转的页面锚点。
- 使用真实产品图片建立可信度，不使用会造成型号误导的 AI 产品图。

## 非目标

- 不修改 Google Ads 广告系列、关键词、预算或出价。
- 不新增后端接口、数据库、CRM 或 Google Tag Manager。
- 不改造其他语言页面。
- 不声称未经确认的价格、库存、认证、客户数量或性能数据。
- 不将 CG 重载水冷描述为带内置倒挡。

## 产品口径

### CG 风冷系列

- 排量范围：150–250cc。
- 主要应用：摩托车、替换市场和轻型运输。
- 卖点：成熟 CG 结构、维护简单、配件通用、可选平衡轴配置。
- 倒挡不做统一承诺，按具体型号和配置确认。

### CG 水冷系列

- 排量范围：150–250cc。
- 主要应用：货运三轮车和持续负载车型。
- 卖点：水冷、持续负载下热状态更稳定、高扭矩、多种配置可选。
- 内置倒挡是可选配置，不得写成全系列标配。

### CG 重载水冷系列

- 排量范围：200–350cc。
- 主要应用：重载货运三轮车、爬坡、高温和持续高负载工况。
- 页面主名称使用“CG 重载水冷系列”，不以 HW 作为主标题。
- 可使用已确认的技术点：20 滚子离合器、18 极磁电机、1.5L 机油容量。
- 不带内置倒挡，页面文案、标签和比较表均不得暗示带倒挡。

## 选择的页面方案

采用单页决策漏斗，而不是产品目录网格或 CG/HW 标签切换。

理由：搜索广告带来的是冷流量。采购商需要先判断自己的用途，再比较系列，最后确认工厂和合作能力。单页结构可以完整展示三类产品，同时允许不同广告组通过锚点直接进入相关区域。

## 页面地址与锚点

- 页面：`/ru/dvigateli-dlya-uzbekistana.html`
- CG 区域：`#cg-engines`
- CG 重载区域：`#cg-heavy-duty`

页面必须在带查询参数时仍正常响应锚点，例如：

`/ru/dvigateli-dlya-uzbekistana.html?utm_source=google&utm_campaign=uz_search#cg-engines`

## 页面内容结构

### 1. 精简页头

- 使用现有 Chixiang Motor 品牌标识。
- 保留 CG、CG 重载、产品比较、关于工厂等页内导航。
- 增加文字明确的俄语主站入口“Русский сайт”，链接到 `ru/index.html`；品牌标识同样链接到俄语首页。
- 右侧放置 WhatsApp 按钮。
- 手机端始终保留可触达的 WhatsApp 主操作，并在首屏次级操作或页脚保留俄语主站入口。

### 2. 首屏

- H1：俄语表达“面向乌兹别克斯坦摩托车和货运三轮车的 CG 发动机”。
- 副标题同时说明 CG 150–250cc 与 CG 重载水冷 200–350cc。
- 主要按钮：通过 WhatsApp 获取报价。
- 次要按钮：进入俄语主站；产品区通过页头锚点和首屏下方内容继续承接。
- 使用用户提供的 1672×941 发动机产品线横幅作为首屏主视觉，源文件转换为 WebP 后放入站点图片目录。
- 桌面端将横幅铺满首屏：左侧深蓝留白承载白色俄语标题、说明和按钮，右侧保留横幅中的三台发动机。
- 删除原首屏单台发动机白色卡片和“150–350 cm³”悬浮角标，不再叠加第二套产品图。
- 横幅含 CG、CB 和重载发动机，因此首屏图片语义统一标注为“Chixiang 工厂发动机产品线”；页面标题与正文仍聚焦 CG，避免把三台发动机都描述为 CG。
- 手机端不使用高纵横比背景裁切：先完整显示 16:9 横幅，再在深蓝色内容块中展示标题与 CTA，确保发动机和横幅文字不被裁掉。
- 首屏可信信息：始于 2003 年、批量供货、OEM/ODM、出口支持。

### 3. 按使用场景选择

用三个简短卡片说明：摩托车、货运三轮车、持续重载环境。每张卡片引导到适合的产品区域，不制造无法验证的性能承诺。

### 4. CG 产品区域

同一区域内分别展示：

- CG 风冷 150–250cc。
- CG 水冷 150–250cc，可选内置倒挡。

两个系列使用真实图片、排量标签、适用场景、关键特点和带系列信息的 WhatsApp CTA。

### 5. CG 重载水冷区域

- 主标题：CG 重载水冷发动机 200–350cc。
- 明确适用于持续高负载、爬坡和高温工况。
- 展示 20 滚子离合器、18 极磁电机、1.5L 机油容量。
- 明确不带内置倒挡。
- 使用独立 WhatsApp CTA，并在预填消息中说明咨询重载系列。

### 6. 系列比较

比较 CG 风冷、CG 水冷和 CG 重载水冷：

- 排量范围。
- 冷却方式。
- 主要用途。
- 内置倒挡状态。

倒挡一栏必须分别为：CG 风冷“按型号确认”、CG 水冷“可选”、CG 重载水冷“无”。

### 7. 合作流程与信任

- 需求提交。
- 选型与报价。
- OEM、包装和订单确认。
- 生产、质量控制和出口发货。

信任信息限于网站已经具备证据的内容：工厂始于 2003 年、发动机生产、质量控制、OEM/ODM 和出口支持。

### 8. FAQ

回答采购商最常见的问题：

- 如何选择 CG 风冷、CG 水冷或 CG 重载水冷？
- 哪些产品可选内置倒挡？
- 是否支持 OEM/ODM？
- 如何获得价格和交货时间？

### 9. 最终询价区域

- 左侧再次强调 WhatsApp 是最快的询价方式。
- 右侧复用现有俄语询价表单逻辑。
- 表单收集姓名/公司、邮箱或 WhatsApp、产品系列、数量和具体要求。
- 手机端提供底部固定 WhatsApp 按钮，同时为正文预留空间，避免遮挡内容。

## 视觉设计

### 风格

- 延续现有网站的深蓝、白色和工业灰色体系。
- 绿色只用于 WhatsApp 主 CTA。
- 使用克制的阴影、16px 左右圆角和清晰边框，不使用玻璃拟态或装饰性强的动画。
- 保持单一主 CTA；次要链接降低视觉权重。

### 主站引流

- Google Ads 落地页仍以 WhatsApp 询盘为主要转化，不把用户自动重定向到主站。
- 页头使用明确文字“Русский сайт”链接俄语首页，解决仅靠 Logo 不易被识别的问题。
- 首屏次级按钮链接俄语主站，视觉权重低于绿色 WhatsApp 按钮。
- 页脚提供“俄语首页 / 全部发动机 / 工厂介绍”三个入口，分别链接 `index.html`、`products.html` 和 `about.html`。
- 所有主站链接保持同窗口导航，便于用户继续浏览并保留来源参数的浏览器上下文；不制造新的弹窗。

### 产品图片区

- 不裁切发动机关键部位，也不强行让产品图片铺满容器。
- 原图自带白底，因此整个图片舞台使用纯白，消除灰色背景上的白色方块感。
- 桌面和平板采用图片与文字左右分栏，CG 水冷与 CG 重载水冷区左右交错。
- 只有小于约 680px 的手机宽度才改成图片在上、文字在下。
- 图片区域使用固定比例和尺寸，避免累计布局偏移。

### 图片轮播

- 每个产品系列使用 3–5 张真实图片。
- 约 6 秒自动切换；不同产品区可错开约半秒，避免同时变化。
- 提供上一张、下一张、圆点和当前张数。
- 鼠标悬停、键盘聚焦、手机触摸或手动切换后暂停。
- 模块离开可视区域或页面进入后台时暂停。
- `prefers-reduced-motion: reduce` 时禁用自动轮播和淡入动画。
- 首张图优先加载，其余图片延迟加载。
- 图片失败时移除该图片和对应圆点；如果只剩一张，隐藏轮播控制。

## 响应式与无障碍

- 重点验证 375px、768px 和 1440px。
- 正文移动端基础字号不低于 16px。
- 按钮和轮播控制的可点击区域至少 44×44px。
- 不出现横向页面滚动；比较表可在自身容器内横向滚动。
- 所有产品图使用描述性的俄语 `alt` 文本。
- 保持可见焦点样式和符合语义的标题层级。
- 颜色不是唯一的信息表达方式；倒挡状态同时使用文字。
- 手机固定 CTA 不遮挡表单、页脚或系统安全区域。

## 转化数据流

### WhatsApp

1. 用户点击任何 `wa.me` 链接。
2. 公共 `js/main.js` 记录现有 Google Ads 次要转化：`AW-16777656395/bovKCKOx088cEMvwmsA-`。
3. 浏览器继续正常打开 WhatsApp。
4. 每个系列的链接使用不同俄语预填消息，说明咨询的是 CG 风冷、CG 水冷或 CG 重载水冷。

### 询价表单

1. 用户提交表单。
2. 现有公共逻辑向 `/api/contact` 发送请求。
3. 只有服务器返回成功时才记录既有表单主要转化。
4. 错误时保留表单内容并显示可恢复提示，不记录成功转化。

页面不得主动删除 URL 中的 UTM 或 GCLID 参数。

## SEO

- 一个俄语 H1。
- 俄语 `title` 和 `meta description` 覆盖 CG 发动机、货运三轮车和乌兹别克斯坦需求。
- 添加 canonical 与 Open Graph 元数据。
- 添加 FAQPage 结构化数据；不在没有价格和库存的情况下创建虚构 Offer。
- 将新 URL 添加到 `sitemap.xml`。
- 页面保持可索引，不添加 `noindex`。

## 错误处理

- Google Ads `gtag` 不可用时，不阻断 WhatsApp 或表单操作。
- 图片加载失败时，轮播跳过失败图片。
- JavaScript 不可用时，首张产品图、正文、WhatsApp 链接和表单仍可使用。
- 表单错误在相关区域明确提示原因和下一步。
- 锚点在页头固定时保留足够 `scroll-margin-top`，避免标题被遮挡。

## 验证方案

### 自动检查

新增页面测试，至少验证：

- 页面存在且引用公共脚本、页面专用 CSS 和页面专用 JS。
- CG 风冷 150–250cc、CG 水冷 150–250cc、CG 重载水冷 200–350cc 均出现。
- CG 水冷明确为可选内置倒挡。
- CG 重载水冷明确为无内置倒挡。
- `#cg-engines` 与 `#cg-heavy-duty` 存在。
- 页面包含 WhatsApp 链接、询价表单和现有公共跟踪脚本。
- canonical、描述、FAQ 结构化数据和站点地图条目存在。
- 所引用的本地图片文件存在。

### 浏览器检查

- 375px、768px、1440px 无页面横向滚动。
- 桌面和平板产品区左右分栏，手机产品区上下排列。
- 轮播自动播放、手动切换、暂停、离屏暂停和减少动态效果均符合设计。
- 键盘可访问轮播、导航、WhatsApp 和表单。
- 表单成功、失败和加载状态正确。
- WhatsApp 可正常打开且预填产品系列正确。
- 页面加载时无明显图片跳动。

### 上线检查

- 正式 URL 返回 200。
- canonical 指向正式 URL。
- Google 全局标签和两个既有转化目标仍存在。
- WhatsApp 点击和表单成功分别触发正确的转化事件。
- 新页面已出现在 `sitemap.xml`。

## 验收标准

- 页面技术口径与本设计的三类产品定义一致。
- CG 水冷不再把倒挡写成标配；CG 重载水冷不再声明内置倒挡。
- 页面能够通过锚点服务 CG 和 CG 重载广告流量。
- 桌面、平板和手机均具备专业、紧凑且无明显布局问题的视觉效果。
- 真实产品轮播不会阻碍阅读或造成明显性能问题。
- WhatsApp 和询价表单转化逻辑沿用并通过验证。
- 不包含未经确认的销售或技术承诺。
